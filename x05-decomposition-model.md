# 5 Organic Decomposition Model

## 5.1 Objective and Target Variables

The organic decomposition model estimates the composition of the upper meter of the soil surface as a percentage of three material classes: fibric, hemic, and sapric. These classes describe the decomposition state of the mapped peat extent. Where the probability model identifies areas that are likely to contain peat and the depth model predicts its thickness, the composition model characterizes the material in the top meter. This is relevant to carbon stock estimation because decomposition state is closely tied to bulk density. More decomposed (sapric) peat is typically denser than less decomposed (fibric) peat, so an equal thickness of sapric peat holds more carbon per area. Carbon concentration varied little between classes from data in the Minnesota Peat Inventory (mean 50.67%, SD 4.77% across 533 measured horizons) making bulk density influential on carbon stock calculations.

The model predicts three target variables: Fibric_pct, Hemic_pct, and Sapric_pct. Training data comes from the MN DNR Peat Inventory which contains horizon level decomposition classifications. Horizons observations were restricted to the top meter of the profile for this specific training set. The uncertain \`Unknown_pct ' category was dropped, and the remaining three classes were normalized to sum to 100% per pedon. The resulting dataset (`organic_composition_features_combined.csv`) contains 18,041 observations.

Model training and spatial inference were restricted to the peat mask generated by the probability model (PROB_LGBM_V2 ≥ 0.362) workflow described for the depth model.

## 5.2 Modeling Compositional Targets

The three target variables represent a portion of the top meter of peat and therefore must sum to 100%. Standard regression models do not account for or enforce sum constraints, so predicting each of the targets separately can produce results whose sum is not equal to 100%. Two modeling strategies were evaluated to address this issue:

Independent regression. A separate regression model was trained for each class, allowing each model to optimize on its own target. The predictions are not constrained to sum to 100%. This approach was evaluated in experiments 421 and 422 in 03-peatland-carbon-modeling.

Iterative residual regression. In the alternative approach, classes were predicted sequentially. Fibric percentage was predicted first, then hemic percentage as a fraction of the remainder (100% − fibric), and sapric percentage was assigned whatever was left. This guarantees a sum of 100% but introduces an order dependency. Errors in the first predicted class carry into every class predicted after it, and the last class (sapric) absorbs the combined error of all earlier predictions rather than being modeled independently. This approach was evaluated in experiment 426 (COMP_RF_001).

In an initial Random Forest comparison using random cross-validation, independent regression achieved a mean R² of 0.4341, compared with 0.3999 for iterative residual regression. This comparison was run on the earlier version of the dataset (10,679 points, random cross-validation only). Independent regression was retained as the primary strategy.

Post-inference normalization. The final pipeline retained independent per-target regression for all three classes and applied a post-inference normalization step to constrain to a sum of 100% after the prediction instead of during it. For each valid pixel the three raw predictions were divided by their sum and multiplied by 100.

```
total  = Fibric_pred + Hemic_pred + Sapric_pred
normed = (class_pred / total) * 100
```

This preserves the relative proportions predicted by the individual models while ensuring that all 3 targets sum to 100%. Unlike iterative residual regression it does not favor targets that are predicted first.

## 5.3 Model Selection and Spatial Prediction

Random Forest, XGBoost, and LightGBM were compared for each composition target. Recursive feature elimination (RFE) was applied to the Random Forest models only, with a separate feature set selected for each target. The final algorithm for each target was selected by spatial cross-validation R² (50 km blocks).

Table RFE feature sets for the Random Forest models.

| Target | RFE features | RFE spatial R² |
|---|---|---|
| Fibric | 24 | 0.1053 |
| Hemic | 30 | 0.0783 |
| Sapric | 32 | 0.1650 |

Table Base (untuned) cross-validation results by algorithm, reported as spatial R² / random R². The best spatial R² for each target is in bold.

| Target | Random Forest | XGBoost | LightGBM |
|---|---|---|---|
| Fibric | 0.105 / 0.38 | 0.08 / 0.41 | 0.156 / 0.436 |
| Hemic | 0.137 / 0.31 | 0.060 / 0.43 | 0.216 / 0.446 |
| Sapric | 0.207 / 0.570 | 0.189 / 0.586 | 0.204 / 0.577 |

LightGBM achieved the highest spatial R² for fibric and hemic percentage. For sapric percentage, Random Forest performed marginally better than LightGBM (0.207 versus 0.204) so Random Forest was selected for sapric and LightGBM for fibric and hemic.

Table Final composition models and cross-validated performance.

| Target | Final model | Spatial R² | Random R² | Random MAE |
|---|---|---|---|---|
| Fibric | COMP_LGBM_FIBRIC_PCT_TUNED | 0.156 | 0.436 | 11.9% |

| Sapric | COMP_RF_SAPRIC_PCT_TUNED | 0.207 | 0.570 | 13.5% |

The selected models were applied independently to generate statewide predictions at 10m resolution within the peat mask, and the normalization step was applied to produce layers with a consistent total. Each component map was written as a Cloud-Optimized GeoTIFF with uint8 encoding (pixel value × 0.5 = percent, nodata = 255).

## 5.4 Model Performance and Limitations

Composition models performed substantially worse under spatial cross-validation than under random cross-validation. Across the three targets, spatial R² ranged from 0.16 to 0.22, compared with 0.44 to 0.57 under random cross-validation. Spatial R² is also the lowest of the three model families in this project.
